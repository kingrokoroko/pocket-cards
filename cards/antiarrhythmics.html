抗不整脈薬 ― Vaughan Williams と Sicilian Gambit

分類編（第1版）／ Vaughan Williams classification・Sicilian Gambit・vulnerable parameter ／ 救急・集中治療 ／ 作成 2026-09-08

2つの分類は競合していない。Vaughan Williams は「薬を語るための語彙」、Sicilian Gambit は「不整脈から薬に至るための手続き」で、階層が違う。 VWは薬ではなく作用の分類であり、1剤が複数クラスに属する（アミオダロンはⅠ〜Ⅳ全部を持つ）。 この点を忘れて「クラスで選ぶ」をやった結果が CAST ―「PVCを消せば予後が良くなる」という代替エンドポイントの敗北であり、これが Sicilian Gambit を生んだ。 実務ではクラスで覚え、機序（vulnerable parameter）で選び、器質的心疾患の有無で切る。

1Vaughan Williams ― まずⅠ群の読み方 a/b/c は「Na以外に何を持つか」で決まる

Ⅰ群
Naチャネル遮断薬。phase 0 の立ち上がりを抑え、伝導速度と興奮性を下げる。ここまでは a/b/c 共通。
Ⅰa群
Naチャネル遮断 ＋ Kチャネル遮断。再分極も遅れるので APD／不応期は延長し、QRSもQTも延びる。
Ⅰb群
不活性化型（inactivated state）Naチャネルの遮断薬。脱分極して不活性化型が滞留する組織 ― 虚血心筋・活動電位の長い心室 ― に選択的に効く。APDはむしろ短縮。
Ⅰc群
Kチャネル遮断を持たない純粋なNa遮断。APDはほぼ不変で、QRSだけが延びる。チャネルからの解離が最も遅く、伝導抑制が強く残る。
心室筋の活動電位と各クラスの作用点

Ⅰa群は phase 0（Na）と phase 3（K）の両方に矢印が立つ。Ⅰb群は phase 0 に効きつつ APD をむしろ短縮させ、Ⅰc群は phase 0 のみ。心電図で見えるのは phase 0 → QRS、phase 3 → QT（JT）という対応。

2Vaughan Williams 分類の全体 分類しているのは薬ではなく「作用」

!
1剤＝1クラスではない。アミオダロンはⅠ〜Ⅳ全部（Na・Ca・K・α/β遮断）、ソタロールはⅡ＋Ⅲ、プロパフェノンはⅠc＋β遮断、ベプリジルはⅢ＋Ⅳ＋Na遮断。 さらに活性代謝物が親化合物と別クラスのことがある ― プロカインアミドの NAPA は純粋なⅢ群で腎排泄であり、腎不全では親薬が適量でもTdPを起こす。

3Ⅰ群の3亜型 ― 解離速度がすべてを決める use-dependence の強さ＝Ⅰc ＞ Ⅰa ＞ Ⅰb

classⅠa
Na（解離 1〜10秒）＋ K遮断。脱分極も再分極も抑えるのでQRSとQTの両方が延びる。上室にも心室にも効く反面、TdP（キニジン失神）と陰性変力作用が制限になる。 ジソピラミドは抗コリン作用が強く（尿閉・緑内障悪化・口渇）、シベンゾリンとジソピラミドは低血糖（膵β細胞のKATP遮断でインスリン分泌↑、腎機能低下例と高齢者で顕在化）を起こす。シベンゾリン・ジソピラミドは腎排泄。
classⅠb
不活性化型Naチャネルを選択的に遮断（解離＜1秒）。正常に分極した心筋ではチャネルから素早く離れるため実質的に効かず、脱分極・虚血・頻拍で不活性化型が滞留する組織にだけ効く＝電気生理学的な「病巣選択性」。 心房には無効（心房は活動電位が短く不活性化型に留まる時間が足りない）。APDは短縮し、QRS・QTはほぼ動かない。リドカインは肝血流依存（心不全・肝硬変で減量）、中毒は痙攣から。
classⅠc
解離＞10秒。Kチャネル遮断を持たない。次の拍が来てもチャネルが空かず遮断が蓄積する（強い use-dependence）ため、頻拍時ほど強く効く一方、伝導抑制が拍間に残りリエントリーの基質そのものになる。 発作性AF・上室頻拍には非常に有効だが、陳旧性心筋梗塞・低EF・心不全では禁忌（CAST）。ピルシカイニドは約9割が腎排泄で、腎機能低下時にQRS著明延長・心停止をきたす。

4なぜ Sicilian Gambit が要ったのか ― CAST 分類が壊れたのではなく、分類の使い方が壊れた

CAST（Cardiac Arrhythmia Suppression Trial, NEJM 1991）RCT
  • 仮説：心筋梗塞後の心室期外収縮を抑えれば突然死が減る。PVCの抑制を代替エンドポイントとして薬を選んだ。
  • 設計：まずオープンラベルでPVCが抑制された症例だけを無作為化（エンカイニド／フレカイニド／モリシジン vs プラセボ）。「効いた人だけ」を選んで組み入れている点が重要。
  • 結果：1498例、平均10か月で89例死亡。不整脈死 43（実薬 n=755）vs 16（プラセボ n=743）、P=0.0004。非不整脈心臓死も 17 vs 5（P=0.01）。総死亡 63 vs 26。エンカイニド／フレカイニド群は途中で中止された。
  • 読み方：PVCは消えていたのに死亡は増えた。抑えていたのは不整脈ではなく心電図上の指標で、同じNa遮断が瘢痕心筋ではリエントリーの基質として働いた。
!
CASTが否定したのはⅠc群という薬でも、Vaughan Williams という分類でもない。否定されたのは「クラス名と代替エンドポイントだけで薬を選ぶ」という手続きであり、器質的心疾患という基質を無視したこと。この反省から1990年にタオルミナで合議され、翌年 Sicilian Gambit が出た。
Vaughan Williams 分類の構造的な限界（4点）
  • 薬ではなく作用の分類なのに、薬の分類として使われる。実薬は複数クラスにまたがる。
  • 不整脈の機序と結びついていない。「上室性ならこれ」式の経験則しか導けず、なぜ効くかを説明しない。
  • 分類に入らない薬が増えた（ジゴキシン、アデノシン、Mg、イバブラジン）。
  • 活性代謝物・自律神経作用・基質（虚血や線維化）を表現できない。

なお2018年に Oxford のグループが Class 0（If）〜Ⅶ（上流治療）まで拡張した修正版を出しており、Ⅰ群には後期Na電流阻害（ラノラジン）が Ⅰd として、Ⅳ群には RyR2・SERCA など細胞内Ca動態が加えられている。分類の枠組み自体は今も更新され続けている。

5Sicilian Gambit ― 分類ではなく手続き 薬から入らず、機序から入る

Sicilian Gambit は薬に新しい名前を付け直したのではない。「この不整脈を止めるには、どの電気生理学的パラメータを動かせばよいか」を先に決め、そのパラメータを担うチャネル・受容体・ポンプに作用する薬を、薬剤×標的のマトリクスから選ぶという手順を提案した。チェスの序盤定石になぞらえた名前も、この「手順」という含意による。

STEP 1
機序を決める
自動能亢進か、triggered activity（EAD／DAD）か、リエントリーか。ここを外すと以降すべて外れる
STEP 2
vulnerable parameter
その機序を最小の介入で壊せるパラメータ。伝導・興奮性・不応期・phase 4・細胞内Ca のどれか
STEP 3
標的を決める
そのパラメータを担うチャネル（Na/Ca/K/If）・受容体（α/β/M2/A1）・ポンプへ翻訳する
STEP 4
薬を選ぶ
標的に作用する薬をマトリクスから選び、心機能・腎肝・併存症で絞る
i
実務での立ち位置。Sicilian Gambit は処方の手順として日常的に回すものというより、薬を選ぶときの思考の枠として使われている。国内では JCS/JHRS 2020 不整脈薬物治療ガイドラインが、薬剤の作用をこのマトリクス形式で掲載している。臨床の最初の分岐は今も「器質的心疾患があるか」「心機能はどうか」「腎・肝はどうか」であり、Gambit はその上でなぜその薬なのかを言語化する役割を担う。

7使い方の大原則 分類より先に守ること

① 抗不整脈薬は「不整脈が停止したら中止する」薬最重要
  • 目的は不整脈を止めることであって、止まった後も血中濃度を維持することではない。停止したらそこで終了し、漫然と続けない。
  • 止まった後に残るのは陰性変力作用・伝導抑制・催不整脈作用だけで、得るものがない。抑制を続けるほど良いという発想の帰結が CAST（PVCは消えたのに死亡が増えた）。
  • 再発予防が要るなら、薬を続けるのではなく誘因（虚血・電解質・カテコラミン・低K/低Mg・アシドーシス・容量）を潰すのが先。
② Naチャネルブロッカー（Ⅰ群）は持続投与しない心抑制
  • Ⅰ群は心抑制（陰性変力）が著しい。単回静注で止めるための薬であり、持続点滴で維持する薬ではない。
  • 持続すると蓄積とともに QRS延長 → 血圧低下 → 徐脈・心停止 へ向かう。use-dependence により頻拍が続いている間ほど遮断が蓄積することも効いてくる。
  • とくに器質的心疾患・低EF・虚血例では投与そのものを避ける（CAST）。腎排泄のピルシカイニド、腎排泄＋低血糖のシベンゾリンは腎機能低下例で一段と危険。
③ Kチャネルブロッカー（Ⅲ群）は持続投与してよい維持できる
  • 不応期を延ばしてリエントリーの再発を抑えるのが作用で、心抑制が乏しいため維持投与に耐える。難治性VT/VF・electrical storm でボーラス後に持続へつなぐのはここ。
  • 代わりに監視するのはQT（TdP）。持続中はQTc・K・Mg・徐脈と pause を追う。Ⅲ群のTdPは徐脈・pauseで出る（逆使用依存性）ので、徐脈化させる要素を同時に足さない。
  • アミオダロンは多チャネル遮断のためTdPが少ないが血圧低下（静注では溶媒の寄与も大きい）があり、ニフェカラントは純粋なIKr遮断で血行動態に優しい代わりにTdPが最大の副作用。
!
この3つを合わせると、実際の使い分けは「Ⅰ群＝止めるための一発、Ⅲ群＝止めた後も繋げる薬」という形になる。止まったら中止という原則（①）はⅢ群でも変わらず、持続してよいことと持続すべきことは別。

8落とし穴 分類を字義通りに読むと間違えるところ

  • 「Ⅲ群だからTdP」ではない。アミオダロンはAPDを延長するのにTdPは1%未満で、多チャネル遮断のため再分極のばらつきが増えないことによる。危ないのは純粋なIKr遮断（ソタロール、ニフェカラント、キニジン）。
  • 逆使用依存性（reverse use-dependence）。純粋Ⅲ群は徐脈のときに最もAPDが延び、頻拍では効きが落ちる。「止めたい頻拍には効かず、危ないpauseでだけ延びる」という最悪の向き。アミオダロンはこれが弱い。
  • 使用依存性（use-dependence）。Ⅰ群のNa遮断は頻拍時ほど強い（Ⅰc＞Ⅰa＞Ⅰb）。だからⅠbは正常心拍ではほぼ効かず、心房細動には無効（心房の活動電位が短く不活性化型に留まらない）。
  • Ⅰc薬で心房粗動が1:1伝導になる。Ⅰcで心房レートが300→200程度に落ちると房室結節が追いつき、wide QRS の1:1伝導で血行動態が破綻する。Ⅰcを心房性頻脈に使うときは房室結節抑制薬（β遮断／Ca拮抗）を併用する。
  • WPW＋心房細動に、房室結節だけを抑える薬は禁忌。ベラパミル・ジルチアゼム・ジゴキシン・アデノシンは副伝導路の順行伝導を相対的に増やしVFへ。この場面はプロカインアミド等のNa遮断か、不安定なら電気的除細動。
  • wide QRS tachycardia への「診断的ベラパミル」は禁忌。VTだった場合に血行動態が破綻する。鑑別がつかないうちはVTとして扱う。
  • クラス名は薬ではなく作用。プロカインアミドの活性代謝物 NAPA は純粋なⅢ群かつ腎排泄で、親薬の血中濃度が適正でも腎不全ではTdPが起こる。プロパフェノンはβ遮断作用を併せ持ち、喘息では気管支攣縮を起こす。
  • Ⅰa群の低血糖と抗コリン作用。シベンゾリン・ジソピラミドは膵β細胞のKATP遮断で低血糖を起こす（高齢・腎機能低下で顕在化）。ジソピラミドは尿閉・緑内障悪化・口渇。「抗不整脈薬で意識障害」を見たらまず血糖。

エビデンスの質と、このカードの限界

分類そのものはエビデンスではなく枠組みである。Vaughan Williams 分類（1970／1984 再評価）も Sicilian Gambit（1991）も、RCTで検証された対象ではなく専門家による整理・合議である。したがって「Gambitで選んだ方が予後が良い」ことを示した試験は存在しない。一方でCASTは分類の使い方に対する反証としてのRCTであり、このカードで唯一の一次エビデンスにあたる。
