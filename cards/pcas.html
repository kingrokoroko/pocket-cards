PCAS ― 体温 / 呼吸循環 / 神経学的予後予測

Post-cardiac arrest syndrome ／ ROSC後の集中治療 ／ 救急・集中治療 ／ 作成 2026-08-09

骨格は4つ。①体温は「深く冷やす」より「発熱させない（<37.5℃）」が現在の基本。 ②ただし中間の重症度層には33℃が効く可能性が残っており、検証RCTが進行中。 ③神経学的予後予測は ROSC後72時間以降・multimodal・偽陽性0%（0%FPR）の所見でのみ行う。単一指標での治療中止は禁忌。 ④呼吸循環はおおむね標準的目標（SpO2 90–98%、PaCO2 35–45、MAP>65）で、ECMO中の高酸素だけは意識して避ける。

3体温管理 ― なぜ「低体温」から「発熱予防」になったのか

読み方は「対照群が何度だったか」。2002年の2試験は対照群に体温指定がなく、実測で38℃近くまで発熱していた。 つまり示されたのは「低体温が良い」ではなく「発熱が悪い」だった可能性がある。 対照群を36℃・37.8℃以下と厳格に管理した TTM・TTM2 では差が消えた ―― これが「深部低体温から発熱予防へ」の実体。 ただし HYPERION は対照を37℃で厳格管理してなお non-shockable で差を出しており、「発熱予防だけで全部説明できる」とも言い切れない。 この矛盾が、次節の「重症度で層別化する」につながる。

4High-quality TTM の5要素「冷やした」ではなく「どう冷やしたか」

1開始時期
できるだけ早く。ただし病院前（院外）での冷却はエビデンスがなく推奨しない。 TTM2 では心停止から無作為化まで135分、目標体温到達までさらに180分かかっている。実臨床でこれ以上早くするのは難しいという現実的制約がある。冷却カテーテルを入れないと始まらないので、方針が決まった時点でデバイスを手配する。
2目標体温
37.5℃ 以下（発熱予防）。ただし低体温が効く亜集団が存在する可能性は残っている。 ILCOR の定義は TTM から Hypothermic ／ Normothermic ／ Fever prevention ／ No temperature control の4区分へ変わった。用語は煩雑なので、実務では「何度を目標に、何で、どれだけ維持するか」を具体的に指示すればよい。
3持続時間
最低36時間。それより長くしても上乗せは示されていない。 24h/48h、36h/72h いずれのRCTも差なし。48時間群では有害事象とICU滞在が増えるため、漫然と延長しない。
4管理方法
血管内冷却 > 体表冷却（どちらも使えるなら血管内）。 TTM2 の post hoc（Intensive Care Med 2025）では血管内が cooling performance で優位 ―― 目標到達が早く、維持中の温度変動が小さく、overcooling と TTM後発熱が少ない。ただし神経学的予後は IPTW 調整後には差がない。 自施設で使えるのは サーモガード（血管内） と アークティックサン（体表）。フィードバック機構とコア体温モニタがあることが「high-quality」の最低条件で、冷たい水をかけるだけ・shivering 未管理は low-quality。
5復温
ゆっくり。12〜24時間かけて。 試験で用いられた速度は 0.25〜0.5 ℃/h。復温後に発熱させないところまでがTTMで、BOX では早く復温した側で 37.7℃以上の発熱が増えた。「12〜24時間」という具体値は講義の口頭補足であり、スライドには記載がない。
◆
全員にやる必要はない。GCS ≧ 8 は TTM の適応なし。 逆側の端 ―― GCS 3 で高度脳浮腫がある患者にTTMを行うかは議論があり、他に予後を示唆する所見がなければ積極的にはやらない、というのが講義での立場だった。

5重症度で層別化するなぜ全体では差が出ないのか

「全体で差が出ない」＝「誰にも効かない」ではない。 低severityは何をしても生存し、high severityは何をしても死亡する。TTMの上乗せが出るとすれば中間層という解釈で、 moderate severity を対象に 33/34℃ を検証するRCTが現在進行中（自施設も参加中）。現時点では可能性の段階であり、標準診療ではない。

6Shivering ― 管理しなければTTMは成立しない

評価は BSAS（Bedside Shivering Assessment Scale）まず数値化する

  1. 体表加温（skin counterwarming） ― 耳・手・足など末梢を温める。自施設の研究では有意差が出なかった（手足に当てる方式で実施）。体幹前面やもう少し中枢寄りを温めた方が効くのでは、というのが講義での私見 自施設研究・陰性
  2. 鎮静鎮痛 ― デクスメデトミジン、ケタミンを含めて調整する。実務上ここが主軸
  3. アセトアミノフェン
  4. マグネシウム ― sMg < 4 mg/dL で 1 g/h。効果は限定的
  5. 筋弛緩 ― 本気で止めたいときの手段。BISを併用する。けいれんなどの臨床所見が隠れる点に注意 最終手段
!
筋弛緩をかけた時点で「臨床でのけいれん」は見えなくなる。 shivering 制御のために筋弛緩を使うなら、脳波でのモニタリングをセットで考える。 予後予測の材料を自分で消してしまわないこと。

7呼吸管理目標は標準的。ECMOの酸素だけ別に考える

SpO₂ 90–98%  /  PaCO₂ 35–45 mmHg  /  30度挙上
PaO2 は AHA 60–105、ERC 75–100 mmHg。低酸素も高酸素も避けるという以上のことは言えていない。呼吸回数を「20回程度」とする指示は講義の口頭補足のみで、スライドに記載はない。

8循環管理

  • 低血圧を避け MAP > 60–65 mmHg。必要に応じて輸液・ノルアドレナリン・ドブタミン・MCS（IABP／ECMO／IMPELLA）
  • ST上昇があれば緊急CAG/PCI。ST上昇がなく、ACSが強く疑われるのでなければCAGは遅らせるべき
  • post-resuscitation myocardial dysfunction（気絶心筋）は 24–72 時間で回復しうる。虚血再灌流による可逆性の心機能低下であり、初期の心機能だけで見限らない
  • ECPR ではやや高め（MAP > 70–80 mmHg）が良いかもしれないが、観察研究のみでRCTはない
  • 個別化MAP（personalized MAP）が良いという明確なエビデンスは現時点でない
!
ECMO症例で「最初まったく動かないから駄目だ」と判断するのは早い。 数日で自然に動き出すことがある。心機能を理由とした早期の方針決定は、神経学的予後予測（72時間）とは別の話として、それ自体が時期尚早になりうる。

9神経学的予後予測このカードで最も間違えてはいけない節

×
原則は3つ。①multimodal（単一指標に頼らない）②ROSC／復温後72時間以降 ③偽陽性0%（0%FPR）の所見でのみ判断する。 回復の可能性がある患者の治療を中止することは取り返しがつかないため、感度を犠牲にしてでも特異度を取る。

72時間の縦線より左では「治療を止める判断」をしない ―― 使えるのは情報を集める作業だけ。 自動瞳孔計の NPi ≦ 2 だけが例外的に ROSC直後から 0%FPR を示しており、早期判定の材料として有望。 ただし感度が低いため、これ単独で決めるのではなく NSE 等との組み合わせで感度を補う。

てんかん様放電を薬で叩いても予後は変わらない（TELSTAR, NEJM 2022）。 cEEG で rhythmic/periodic pattern を抗てんかん薬で48時間以上抑制した群と標準治療群を比較し、 抑制は達成できた（56% vs 2%）が神経学的予後に差はなかった。 サブ解析では GPD（全般性周期性放電）は治療で不変、non-GPD では抗てんかん薬群が良さそうという違いがある。 ガイドラインは「予防的抗てんかん薬は非推奨／明らかな発作は治療推奨」で、TELSTAR以降の知見はまだ反映されていない。

10やってはいけないこと

  • 72時間より前に、神経学的予後を理由に治療を中止する → 0%FPR の所見が揃うのは72時間以降
  • 単一指標（CTだけ・瞳孔だけ・ミオクローヌスだけ）で決める → multimodal が原則
  • 48時間以内のミオクローヌスを、EEGを見ずに予後不良の根拠にする → Lance-Adams のように予後良好な例がある
  • 「TTMをした」で満足して質を問わない → 開始時期・目標・持続・方法・復温の5要素が揃って初めて high-quality
  • shivering を放置する → TTMが成立しないうえ、酸素消費が増える
  • 復温を急ぐ／復温後の発熱を許す → 復温後に発熱させないところまでがTTM
  • 病院前から冷やす → エビデンスがなく推奨されない
  • GCS ≧ 8 の患者にTTMを行う → 適応がない
  • ST上昇がないのに慌ててCAGへ送る → ACS疑いが強くなければ急がない
  • ECMO症例で初期の心機能だけを見て見限る → 気絶心筋は24–72時間で回復しうる
  • ECMO中に FiO2 1.0 のまま PaO2 300超を放置する → 下げる。ただし神経質に絞る必要もない

エビデンスの質について

比較的強い（RCT）：33℃ vs 36℃／37.8℃以下で神経学的予後・死亡に差がないこと（TTM・TTM2）、TTMの持続時間を延ばしても差がないこと（TTH48・BOX）、 てんかん様放電の薬物抑制が予後を変えないこと（TELSTAR）、VA-ECMO で酸素目標を絞っても差がないこと（BLENDER）。

中等度：non-shockable での33℃の有益性（HYPERION は陽性だが、TTM2 との統合解析では消える）。自動瞳孔計 NPi/qPLR の 0%FPR（前向きサブ解析）。

弱い（観察研究・post hoc・専門家意見）：rCAST や PCAC による層別化と「中間層に33℃が効く」という仮説（検証RCTが進行中であり、現時点では標準診療ではない）、 血管内冷却の優位性（cooling performance では優位だが調整後の予後は差なし）、ECPR での高めのMAP目標、ECMO中の高酸素の害（交絡の可能性）、shivering に対する各介入。

講義の口頭補足のみでスライドに記載がなく、引用時に確認を要するもの：復温を12〜24時間かけるという具体値、呼吸回数「20回程度」、 skin counterwarming の装着部位に関する私見、自施設のRCT参加状況。
