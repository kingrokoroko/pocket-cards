Gemella 菌血症 ― 拾い方・心内膜炎の追い方・治療

Gemella morbillorum / haemolysans / sanguinis / bergeri ／ 救急・集中治療 ／ 作成 2026-08-19

かつて Streptococcus morbillorum と呼ばれた菌で、臨床上はずっと「viridans group streptococci の仲間」として扱われてきた。 治療も感受性のブレイクポイントも全部そこからの外挿である一方、2023年に IE の診断基準だけが独立して変わった。押さえるのは3点。 ①グラム染色を信用しない ― グラム陰性桿菌に見えることがある ②Duke-ISCVID 2023 で typical pathogen になった。旧基準の感覚だと definite を取り逃がす ③βラクタムは全株効くが、レボフロキサシン耐性が36%ある

1検査室での落とし穴 同定が付かない fastidious 菌として来る

グラム染色が裏切る 最重要

  • 本来はカタラーゼ陰性・通性嫌気性のグラム陽性球菌。対・四連・短連鎖で並び、streptococci に似る。
  • ところが細胞壁が薄く脱色されやすいため、培養条件や継代で gram-variable、ときに グラム陰性桿菌様に染まる。
  • La Scola & Raoult の3例では、1株が small, fastidious, gram-negative rod と初報され Bartonella を疑った精査が走った。標準的なGNR同定系でも同定不能となり、最終的に 16S rRNA で G. morbillorum と確定。残る2例も "gram-variable cocci and coccobacilli"。
  • → 「発育が悪く、どの同定系にも乗らないGNR様の菌」を見たら、Gemella を鑑別に入れて 16S を回す。

どこまで同定できるか

生化学API 系などの表現型同定はviridans 群との相互誤同定が起こる。属レベルの目安どまり。
MALDI-TOF属は取れるが種まで行けないことがある。DB 収載外で「同定不能」と返る株も報告あり。
16S rRNA属の確定には有用。ただし haemolysans group（G. haemolysans / parahaemolysans / taiwanensis）は相互に 99.77〜100% の相同性で、16S では種を分けられない（種の閾値は 98.65%）。
WGS種の確定が臨床的に要るならこれ。現状これが最も識別能が高い。
!
血液培養の陽性化までの時間（time to positivity）を報告した一次文献は見つからない。「発育が遅い」は教科書的記載どまりで、通常の好気・嫌気ボトルで検出されている症例報告から間接的に推し量るしかない。「遅れて生えたから汚染」という判断の根拠にはならない。

模式図①　宿主で振り分ける ― 「Gemella が生えたら即 IE」ではない

この分岐が実務上いちばん効く。同じ「Gemella 菌血症」でも、好中球減少患者では IE を探しに行く意味が乏しく（62例で IE ゼロ）、弁膜症・人工物のある患者では逆に major criterion として扱う対象になる。菌名ではなく宿主で動きを決める。

汚染を疑う所見（原著本文での定義・妥当性検証は未確認）

  • 複数ボトルのうち1本のみ陽性で、他セットと一致しない。
  • カテーテル採血からのみ陽性で、末梢血が陰性。
  • 臨床像が合わず、標的抗菌薬なしで悪化しない。

模式図②　同じ29症例が、基準を変えるだけで判定が変わる

Popova A, Snygg-Martin U, Rasmussen M. Infect Dis (Lond) 2025;57:428-432（スウェーデン IE レジストリ SRIE）。Gemella IE の存在そのものより、この判定シフトのほうが日常診療への影響が大きい。

Gemella IE の臨床像（レジストリ n=29／単施設 n=13）

菌種レジストリでは G. morbillorum 47%・G. bergeri 27%。症例報告の集積（52例）では G. morbillorum 46.3%・G. haemolysans 25.9%・G. sanguinis 13.0%。
背景年齢中央値 70歳、女性40%、自己弁 90%。単施設集積では既存弁膜症54%・先天性心疾患46%が素因、直近3か月の歯科処置3例、IVDU 2例。
罹患弁僧帽弁・大動脈弁がほぼ同率（各43%前後）、二弁膜 18.5%。単施設13例は全例が左心系。
診断単施設13例では血培陽性69%、31% は摘出弁の 16S rRNA PCR のみで診断（弁培養陽性は0例）。血培陰性 IE の原因菌として想起する価値がある。
転帰レジストリで手術率33%・死亡率3%（1例）。単施設13例は手術率100%（選択バイアス）・死亡率0%、追跡中央値2.2年で再発なし。
?
「Gemella IE は viridans より侵襲性が高い」は根拠が薄い。両者を直接比較したコホート研究は見つからない。この通説の出所は症例報告の蓄積で、重症例ほど論文になる出版バイアスがかかっている。最も質の高いレジストリ（n=29）の結論はむしろ「非β溶血性連鎖球菌による IE と臨床像が類似し、予後は比較的良好」。劇症型として身構える理由はない。

4心エコーをどこまでやるか 明文の強い推奨はない。だが実務は決まる

  • 「Gemella 菌血症を検出したら必ずエコー」という明文規定はガイドライン原文に見当たらない。AHA 2015 の「IE を疑う全例に速やかに TTE」は「疑う臨床像がある」が前提で、そもそも当時 Gemella は typical pathogen ですらなかった。
  • ただし 2023年以降は typical pathogen である以上、他に明確な感染巣がなければエコーを行うのが論理的帰結。これはガイドラインの明文ではなく基準変更からの推論である点は区別しておく。
  • 現実の実施率は低い。Mayo コホートで、臨床的に意義ありと判定された161例のうちエコー施行は88例（54.7%）にとどまる。半分近くが評価されないまま終わっている。
  • → 実務上の落としどころ：好中球減少で消化管由来が明らかなら省略しうる。弁膜症・人工弁・先天性心疾患・IVDU・持続菌血症・塞栓症状のいずれかがあれば TTE、陰性でも疑いが残れば TEE。

!
レボフロキサシンの MIC50 0.5 と MIC90 >128 の乖離が意味するもの。これは「やや効きにくい」ではなく二峰性分布で、感受性株は十分効き、耐性株には全く効かない。菌種によっても偏りがあり（G. morbillorum では 9.1% と報告される一方、他菌種でより高率）。口腔内常在菌カバーのつもりでレスピラトリーキノロンを選んでいると、3株に1株を外す。

ブレイクポイントは自前のものではない

  • CLSI M45（fastidious 菌）に Gemella の項目は存在するが、その解釈基準の中身は M100 の viridans group streptococci 基準の準用。名目上は専用項目、実体は外挿。
  • EUCAST に Gemella 固有のブレイクポイントは見当たらない。
  • → 報告された S/I/R は「viridans として読んだ結果」であることを意識して解釈する。

IE を伴わない菌血症単独の期間

  • 明文のガイドライン推奨は存在しない。「7〜14日」といった数字も Gemella に特化した根拠はない。
  • 実務は感染巣とデバイスの有無で決める。除去可能な感染源（歯性・カテーテル・膿瘍ドレナージ後）で、フォロー血培が陰転し IE が否定できていれば短期で足りるという一般原則を当てるほかない。
  • → 期間を決める前に、まず IE を否定したかを確認する。ここが未評価のまま短期で切ると再燃する。

7侵入門戸 口から入るか、腸から入るか

口腔（最頻）

  • 歯周病・不良な口腔衛生・歯科処置が IE 症例の共通背景として繰り返し報告される。
  • 口腔内でも定着部位が種で分かれる：G. morbillorum は歯肉縁上/縁下プラーク、G. haemolysans は頬粘膜・角化歯肉、G. sanguinis は舌背・咽頭・扁桃。
  • → 菌血症を見たら口腔内を実際に見る。歯科コンサルトの閾値を下げる。

消化管

  • 好中球減少・化学療法後の粘膜炎、消化管穿孔、腸間膜静脈血栓性静脈炎などからの報告がある。
  • Mayo コホートで好中球減少群の感染源は消化管とされ、この群に IE はゼロ。
  • → 好中球減少患者では IE を追うより、粘膜炎・腸管病変を探すほうが当たる。

大腸腫瘍との関連 ― S. gallolyticus と同列に扱わない 要注意

  • 香港の菌血症 13,096例コホートで、G. morbillorum 菌血症は後の大腸癌診断と関連（HR 15.2, 95%CI 1.54–150, p=0.020）。Fusobacterium nucleatum（HR 6.89）、Clostridium septicum（HR 17.1）と並んで挙げられている。
  • ただし 95%CI が 1.54〜150 と極端に広い＝分母となる症例数が極めて少ない。点推定値 15.2 を額面どおり受け取れる精度ではない。
  • 大腸内視鏡を必須とするガイドライン推奨は存在しない。「原因不明例では考慮する」という専門家意見レベルにとどまる。
  • → ルーチンでは出さない。ただし侵入門戸が同定できない G. morbillorum 菌血症で、貧血・便潜血・体重減少が揃うなら下部消化管精査に進む。

エビデンスの質と、このカードの限界

この領域に RCT は一つも存在しない。最上位のエビデンスが後ろ向きレジストリ研究（n=29）と単施設コホート（n=238、3属合計）であり、その下は症例集積と症例報告。Gemella に特化した治療ガイドラインも学会推奨も存在しない。治療レジメン・投与期間・ブレイクポイントはすべて viridans group streptococci からの外挿である。唯一 viridans からの外挿でないのは Duke-ISCVID 2023 の typical pathogen 収載だけ。
